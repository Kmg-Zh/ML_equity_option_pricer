# M4 Checkpoint

Date: 2026-03-29

## Goal
Implement a base surrogate model (MLP) for American option pricing and validate against Binomial teacher labels.

## Added
- `src/surrogate/__init__.py`
- `src/surrogate/data_gen.py`
- `src/surrogate/normalizer.py`
- `src/surrogate/mlp.py`
- `src/surrogate/train.py`
- `src/surrogate/evaluate.py`
- `src/surrogate/run_m4.py`
- `tests/test_m4_surrogate.py`

## Implemented scope
- Pure `numpy` MLP (5→64→128→64→1, ReLU) with manual forward/backward.
- Adam optimizer with L2 weight decay.
- Training-data generator using Binomial teacher labels (`AmericanOptionInput`).
- Feature/label z-score normalization and inverse transform.
- Bucketed evaluation by moneyness and maturity (aligned to M3 buckets).
- M4 runner that saves model/normalizer/report artifacts under `artifacts/surrogate/`.

## Environment note
- Current workspace Python is MSYS2 (`mingw_x86_64_ucrt_gnu` tags), which cannot install standard PyPI `torch` wheels.
- M4 uses `numpy` implementation to remain theory-first and executable in this environment.
- `torch` can be introduced in M7 (AD Greeks) after switching to a standard CPython environment.
