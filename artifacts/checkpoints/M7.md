## M7 implementation details
1. AD gradients are computed wrt normalized inputs:
   - x = [log(S/K), T, r, sigma, q]
   - x_norm = (x - mu) / std
2. Chain rule maps AD gradients to Greeks in price units:
   - Delta = dPrice/dS
   - Gamma = d²Price/dS² (piecewise-linear ReLU approximation)
   - Vega  = dPrice/dsigma
3. Added utility to load model + normalizer artifacts from `.npz` files.
